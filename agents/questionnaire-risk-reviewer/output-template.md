# Questionnaire Risk Reviewer — output template

What a review should look like. Only problematic questions get flagged —
a clean question earns silence, not praise.

```
QUESTIONNAIRE FIELDING-RISK REVIEW — [project name]

RISK SUMMARY
| Dimension | Risk | Why |
|---|---|---|
| IR / screener | L/M/H | ... |
| LOI | L/M/H | ... |
| Quotas | L/M/H | ... |
| Mobile | L/M/H | ... |
| Fraud & quality | L/M/H | ... |
| Drop-off | L/M/H | ... |

LOI REALITY CHECK
[N closed questions ≈ X min; N grid rows ≈ Y min; N open-ends ≈ Z min →
rough total vs. claimed LOI. Explicitly labeled illustration — only a
timed soft launch measures real LOI.]

QUESTION-BY-QUESTION FLAGS
S3 — [what breaks] — [fielding consequence] — [fix direction]
Q12 — ...

THE ONE CHANGE THAT MATTERS MOST
[One paragraph: the single edit that buys down the most risk.]

WHAT TO TELL YOUR SUPPLIER BEFORE LAUNCH
- [flags the supplier should know about / can help mitigate]

ASSUMPTIONS MADE IN THIS REVIEW
- ASSUMPTION: ...
```
