# Brief Builder — output template

What a Brief Builder response should look like. If a section doesn't apply
(no contradictions found), the agent says so in one line rather than omitting
the section.

```
SAMPLE BRIEF — [project name]

Audience: [one plain-English sentence]
Qualification criteria:
  - [testable criterion — a screener question could be written from it]
  - ...
Exclusions: [or "none stated"]
Market(s) & languages: ...
Completes (n): [total, and per market/cell where relevant]
Assumed IR: [X]% (basis: [past fielding / published data / client guess /
  ASSUMPTION: ...])
LOI: [X] min ([measured / estimated])
Quotas: [each cell with its target; interlocks flagged explicitly]
Device: ...
Timeline: launch [date], close [date] — deadline is [hard/soft]
Survey hosting: ...
Incentives: ...
Sensitivities / house rules: ...

GAPS & ASSUMPTIONS
- ASSUMPTION: [what was filled in, and why it needs checking]
- MISSING: [what couldn't be filled in at all]

CONTRADICTIONS NOTICED
- [source A says X; source B says Y — needs a decision]

BEFORE THIS GOES TO SUPPLIERS, DECIDE:
1. [decision only a human can make]
2. ...
```
