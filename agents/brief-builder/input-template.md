# Brief Builder — input template

The Brief Builder accepts anything — but the more of this you fill in, the
fewer questions it has to ask. This is the kit-wide
[project intake template](../../templates/project-intake-template.md);
paste it in along with any raw material (emails, notes, docs).

```
PROJECT INTAKE

Project name / internal reference:
Client or stakeholder (anonymize if needed):
What decision will this research inform?

--- AUDIENCE ---
Who are we surveying (in plain English)?
Qualification criteria (the must-haves):
Exclusions (who must NOT take it):
Audience type: [consumer / B2B / HCP / other]

--- SPEC ---
Market(s) / country(ies):
Number of completes needed (n), per market if multiple:
Expected IR (%) and what that estimate is based on:
LOI (minutes) — measured, estimated, or guessed?
Quotas (list each; say if any are interlocked):
Device requirements:
Languages:

--- LOGISTICS ---
Target fielding start date:
Fielding deadline (and what happens if it slips):
Budget or budget range (if shareable):
Survey platform (who hosts/programs it):
Incentives handled by: [supplier / us / unknown]

--- CONTEXT ---
Has this audience been fielded before? What happened?
Known sensitivities (topic, client rules, compliance):
Anything else a supplier would want to know:

--- RAW MATERIAL ---
[paste emails, call notes, Slack threads, anything —
the agent reconciles it all against the fields above]
```
