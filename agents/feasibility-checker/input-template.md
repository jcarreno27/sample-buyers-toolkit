# Feasibility Checker — input template

Paste your brief (the Brief Builder's output drops straight in). If you don't
have a formal brief, fill in what you can below — "unknown" is a legitimate
answer and will be treated as a risk finding, not an error.

```
FEASIBILITY CHECK REQUEST

--- THE SPEC ---
Audience (plain English):
Qualification criteria:
Market(s):
Completes needed (n):
Assumed IR: [%] — based on: [past fielding / published data / guess]
LOI: [minutes] — [measured / estimated]
Quotas (list; flag interlocks):
Device requirements:
Timeline: launch [date], deadline [date] — [hard / soft]

--- HISTORY & FLEX ---
Has this audience been fielded before? What happened?
Which of these can flex if needed: [n / quotas / timeline / quals / none]
Budget pressure: [none / some / severe] (no numbers needed)

--- YOUR BENCHMARKS (optional) ---
[IRs you've actually seen for similar audiences, markets you know
are thin, house rules on LOI, etc.]
```
