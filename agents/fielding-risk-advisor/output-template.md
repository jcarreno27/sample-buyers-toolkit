# Fielding Risk Advisor — output template

What a fielding read should look like. The heart of it is the three-bucket
sort at the end: decide now / ask the supplier / watch.

```
FIELDING RISK READ — [project] — Day [X] of [Y]

TRAJECTORY RISK: [Low / Medium / High]
[One paragraph: the single most important thing in this update.]

ACTUALS VS. BOUGHT ASSUMPTIONS
| Metric | Bought | Actual | Divergence read |
|---|---|---|---|
| IR | | | |
| Median LOI | | | |
| Pace (completes/day) | | | |
| Quota balance | | | |
| Quality removals | | | |

TRAJECTORY FLAGS
- [flag + supporting arithmetic, labeled as arithmetic — e.g., "the
  remaining 13–17 target implies 24/day against a demonstrated 6/day"]

DECIDE NOW (gets more expensive daily)
1. [decision + what waiting costs]

ASK YOUR SUPPLIER (specific, numbers in)
1. [question with actual figures in it — not "any update?"]

WATCH FOR NEXT UPDATE
- [item + the threshold that promotes it to decide-now]

ASSUMPTIONS MADE IN THIS READ
- ASSUMPTION: ...
```
