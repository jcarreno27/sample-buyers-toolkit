# Full kit

The whole sample-procurement team in one prompt: all seven agents plus a
router that figures out which one you need from what you paste.

## Use it in 60 seconds

1. Open [full-kit-prompt.md](full-kit-prompt.md) and copy everything below
   the line.
2. Paste it as the instructions of a **Claude Project** or **Gemini Gem**
   (best — it persists), or into a long-running chat in any tool.
   *ChatGPT note:* the full-kit prompt is longer than Custom GPT
   instructions allow (~8,000 characters), so in ChatGPT paste it as the
   first message of a chat instead — or install the standalone agents as
   individual Custom GPTs (each fits).
3. Paste in whatever you have — messy context, a brief, supplier replies, a
   screener, fielding numbers. It announces which hat it's putting on and
   gets to work. You can also summon a role by name: "act as the Bid
   Comparator."

## When to use this vs. the standalone agents

| Situation | Use |
|---|---|
| One assistant across a project's whole life | Full kit |
| You only ever do one of the jobs (e.g., compare bids) | The [standalone agent](../agents/) — more depth per stage |
| You're not sure what you need | Full kit, or the [agent selection guide](../docs/agent-selection-guide.md) |

[workflow.md](workflow.md) shows how the six stages chain, and
[docs/full-workflow-example.md](../docs/full-workflow-example.md) walks one
project through all of them.
